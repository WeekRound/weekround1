## 🧑‍💻 Challenge: Mini Calculator

Participants were tasked with building a **basic console-based calculator** in 20 minutes using:
- Any programming language
- No external libraries
- Looping until user exits
- Supporting operations: `+`, `-`, `*`, `/`

> A simple task made to test speed, clarity, and real-time coding under light pressure.
